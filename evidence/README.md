# Evidence Screenshots — Guide

This folder will hold the screenshots that prove tool account setup and course enrollment for the FL-01 deliverable.

**No screenshots have been added yet.** You must take and add them manually.

---

## Required files — exact filenames

| Filename | What to capture |
|----------|----------------|
| `claude-account.png` | Your Claude account page (claude.ai) showing your name or email while logged in. |
| `chatgpt-account.png` | Your ChatGPT account page (chat.openai.com) showing your name or email while logged in. |
| `academy-enrollment.png` | The Anthropic Academy page showing you are enrolled in "AI Fluency: Framework & Foundations". |
| `academy-module1-complete.png` | The course progress page or completion badge showing Module 1 is marked as complete. |
| `claude-project-config.png` | Your Claude Project settings page showing the custom instructions you pasted from `docs/claude-project-instructions.md`. |

---

## How to add them

1. Take each screenshot and crop tightly so only the relevant part is visible (no unrelated browser tabs, no sensitive data).
2. Save each file with the **exact filename** from the table above (lowercase, hyphens, `.png`).
3. Place the file in this `evidence/` folder.
4. Update the checkboxes in [`docs/tool-setup.md`](../docs/tool-setup.md).
5. Commit: `docs: add tool setup evidence screenshots`

---

> **Privacy reminder:** Before committing, check that no screenshot contains passwords, payment information, or other private data.
