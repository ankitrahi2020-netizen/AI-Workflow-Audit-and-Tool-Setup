## What this repo is

This repository is the submitted artifact for the **FL-01** course deliverable.  
It contains a personal AI workflow audit, tool-setup evidence, target task definitions for future modules, and custom Claude Project instructions — all grounded in my real week as a B.Tech student in India.

The audit framework is based on Ethan Mollick's *"On-boarding Your AI Intern"* model, which classifies tasks into four buckets: **Just me · Delegate with review · Collaborate · Fully automate**.
